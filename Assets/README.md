# App icon

`AppIcon.png` is the full-resolution DiscShift icon master. `scripts/build-app.sh` generates the standard macOS icon sizes and `AppIcon.icns` from this file. Artwork is covered by the repository's MIT license.

Created with the built-in image generation tool. The design combines a silver optical disc with a single video tile on a blue rounded-square background, expressing the move from disc to watchable episode with a simple silhouette.

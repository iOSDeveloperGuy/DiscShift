DiscShift can now keep itself up to date.

- Check for new versions from the DiscShift menu or Settings.
- Choose automatic update checks and background downloads in Settings.
- Updates wait while a disc is scanning, exporting, or setup is running.
- Updates are verified with both DiscShift's update signing key and Apple's Developer ID signing.

If you're upgrading from 0.8.2, install this version once from GitHub and move it to Applications. Future versions can update in the app.

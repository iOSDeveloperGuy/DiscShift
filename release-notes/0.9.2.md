# DiscShift 0.9.2

- After installation, DiscShift moves its matching Downloads app copy to Trash, including when macOS opens a Safari download from a protected temporary location.
- Opening an already installed matching copy also cleans up the duplicate download. ZIP archives, other versions, and unrelated apps are kept.
- Cleanup verifies both apps' signatures and code identity, preserves macOS quarantine, and never prevents using a successfully installed app if cleanup is unavailable.

This remains an Apple Silicon development preview for macOS 14 and later.

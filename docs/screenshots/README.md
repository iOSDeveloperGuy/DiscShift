# DiscShift screenshots

Captured on October 19, 2026 from the DiscShift 0.9.2 interface, using a separate local app copy with the same views and a separate settings domain. No production UI or app behavior was changed for these captures.

- `show-lookup.jpg`: real online results for All Creatures Great and Small, with the 1978 series selected.
- `episode-order.jpg`: a real scan of the mounted DVD, showing three episode-length titles and one short title marked as a possible extra. Episode names are broadcast-order suggestions, not independently verified DVD-title identities.
- `export-options.jpg`: the export review for one selected title. The library folder is a neutral temporary directory; file sizes are estimates. This screen was captured before starting an export.

All three images are direct 1840 × 1480 window captures. They are not generated interface mockups or evidence of a completed full-disc export or Jellyfin playback. The macOS remote-control indicator is part of the captured window chrome.

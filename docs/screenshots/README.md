# DiscShift screenshots

Captured on October 19, 2026 directly from DiscShift 0.9.2's unmodified SwiftUI content view, using an isolated model and settings domain. The macOS title bar, screen-sharing indicator, and mouse pointer are excluded by capturing the app content before window compositing.

- `episode-order.png`: three episode-length titles and one short title marked as a possible extra. Durations and chapters use recorded values from the physical DVD scan used for the original captures; show and episode metadata was retrieved from TVMaze. Episode names are broadcast-order suggestions, not independently verified DVD-title identities.

The image is a 1840 × 1376 app-content capture. No controls, labels, or results were painted over. It does not establish a completed full-disc export or Jellyfin playback. Only this single screenshot is used in the README.
